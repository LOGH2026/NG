# Northwoods Hunter v5

This version focuses on making the game look as graphically detailed as possible while staying as a simple browser game.

## Main upgrades
- Much more detailed deer art with better anatomy, fur shading, muzzle, eye, throat patch, tail, and antlers
- Much more detailed scoped bolt-action rifle with wood stock, receiver, barrel, bolt, scope body, scope glass, rings, and muzzle flash
- Richer forest scene with layered ridges, tree lines, meadow shading, rocks, stump, fog, grass, and atmospheric particles
- Cursor remains visible on the menu / round-complete screen and disappears only while hunting
