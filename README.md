# Northwoods Hunter

A simple browser hunting game built with HTML, CSS, and JavaScript.

## Play locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save.
7. GitHub will provide a public game URL.

## Controls
- Mouse: aim
- Left click: shoot
- R: reload
- Esc: pause

## Current features
- One .308 hunting rifle
- 5-round magazine + reserve ammunition
- Moving deer at varying depths/speeds
- Deer can walk or flee after shots
- Body, neck, head, and vital hit zones
- Trophy deer bonus
- Score, harvests, and accuracy
- Basic recoil and shot spread
- Responsive browser layout
